# SEA LIVERY — Premium Link in Bio (v3.0)

Одностраничная мини-визитка SEA LIVERY в брендовых цветах. Без PWA, JavaScript, сторонних компонентных библиотек, регистрации и баз данных.

## Установка на GitHub Pages

1. Распакуйте архив и откройте папку `SEA_LIVERY_Bio_v3_GitHub_Pages`.
2. Загрузите **содержимое папки** в корень публичного GitHub-репозитория: `index.html`, `assets/`, `.nojekyll`, `README.md`. Не загружайте сам ZIP вместо файлов.
3. GitHub: Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.
4. После публикации откройте `https://USERNAME.github.io/REPO/` на iPhone (Safari) и Android (Chrome), проверьте каждую кнопку.
5. Для обновления загрузите новые файлы в тот же репозиторий — ссылка остаётся прежней.

## Аналитика и измеримость

Главная ссылка содержит: `utm_source=sea_livery_bio`, `utm_medium=referral`, `utm_campaign=always_on`, `utm_content=main_catalog`.
UTM не являются системой аналитики. Для отслеживания оплаченных заказов убедитесь, что FoodSoul/сайт сохраняет метки в заказе или что настроена аналитика электронной торговли; сама страница не собирает персональные данные.
